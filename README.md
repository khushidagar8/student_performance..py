
# 🎓 AI Student Performance Predictor

A Python-based GUI application that analyzes student marks and attendance to estimate academic performance and generate student reports.

## 🚀 Features

- 📊 Dashboard with total students and average performance
- 👩‍🎓 Student record management
- 🧠 Performance estimation based on marks and attendance
- 📈 Visual performance charts
- 💡 Personalized academic improvement suggestions
- 📁 Export student reports to CSV
- ✅ Input validation and duplicate roll number checking
- 🖥️ User-friendly Tkinter graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- CSV
- ttk
- File Dialogs and Message Boxes

## ⚙️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open `student_performance.py` in Python IDLE.
4. Select **Run → Run Module** or press **F5**.
5. Add student details and explore the dashboard.

No third-party Python packages are required.

## 📋 How It Works

The application uses marks and attendance to calculate an estimated performance score.

**Scoring Formula:**

Score = (Marks × 0.70) + (Attendance × 0.30)

The score is used to categorize performance as Excellent, Good, Needs Improvement, or At Risk.

These are rule-based estimates, not predictions from a trained machine-learning model.
